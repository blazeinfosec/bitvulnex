target: V-45
category: Business logic / Race condition — double-claim
tier-1-basic: |
  A reward-claim endpoint reads unclaimed rows then marks them claimed,
  but not atomically. Fire it twice at once to claim twice.
tier-2-verbose: |
  Claiming staking rewards reads the not-yet-claimed rows, then updates
  them to claimed with no transaction and no claimed-is-null guard on
  the write. Two simultaneous claims for the same position both observe
  the same unclaimed set before either write lands, so each credits the
  full reward. Net N-times payout for N parallel requests. An atomic
  conditional update, or a serializable transaction, would close it.
