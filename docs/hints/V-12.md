category: OWASP / SQLi — second-order
tier-1-basic: |
  A value you control at rest is later concatenated into a raw query
  somewhere else. The write path is safe; a downstream read is not.
tier-2-verbose: |
  A profile field you set through the normal (parameterized, safe)
  update is stored verbatim. An admin-only compliance report later
  iterates active cases and splices that stored value into a raw,
  unparameterized similarity query. Because the dangerous read is far
  from the safe write, this is a second-order injection. Time-based
  blind techniques work; the sink runs server-side under the admin's
  request.
