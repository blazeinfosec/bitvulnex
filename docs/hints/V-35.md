  An auth middleware short-circuits when it sees a particular request
  header — one the client can simply send.
tier-2-verbose: |
  An early branch in the framework middleware returns immediately when a
  subrequest-marker header is present, meant to let internal probes skip
  auth. The header is attacker-suppliable, so sending any non-empty
  value skips the role check ahead of admin handlers. Those handlers
  then trust a client-sent user-id header. This mirrors a known
  framework middleware-bypass CVE-2025-29927. Use it to list the user
  table or mint admin users.
