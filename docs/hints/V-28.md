target: V-28
category: Crypto / Race condition — TOCTOU
tier-1-basic: |
  The balance check and the debit are not in one transaction. Fire two
  requests at once and both see the same funds.
tier-2-verbose: |
  Submitting a withdrawal reads available balance, checks a limit, then
  debits — none of it inside a single transaction. Two near-simultaneous
  requests both read the same balance before either writes, so both
  pass and both debit. Widen the window with parallel, tightly-timed
  requests (single-packet style). The fix would be a conditional debit
  guarded by an available-greater-or-equal predicate, or a serializable
  transaction.
