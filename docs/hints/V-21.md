target: V-21
category: OWASP / Auth — refresh-token reuse
tier-1-basic: |
  Refresh tokens are meant to rotate, but the old one is never
  invalidated when a new pair is issued. A captured token keeps working.
tier-2-verbose: |
  Each refresh call mints a new access/refresh pair but never marks the
  presented refresh token consumed — there is no used-at or revoked-at
  state on the record. A token captured by any means keeps minting
  access tokens for its full multi-week lifetime, even after the
  legitimate user has refreshed. Confirm by replaying the same refresh
  body repeatedly and watching it keep succeeding.
