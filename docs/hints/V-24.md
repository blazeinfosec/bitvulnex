  The address validator is too forgiving. It accepts networks it
  should not, silently cleans some characters, and skips a checksum.
tier-2-verbose: |
  One permissive validator covers mainnet, testnet, and regtest
  prefixes, strips zero-width Unicode before checking, and never
  verifies the bech32 checksum. The zero-width strip is the sharpest
  edge: a string that displays as a victim address to a reviewer
  normalizes server-side to an attacker address once the invisible
  characters are removed. Submit such an address where a withdrawal
  destination is validated.
