target: V-11
category: OWASP / SQLi
tier-1-basic: |
  An admin search endpoint has a "perf mode" toggle. Behind it, the
  query builder takes a shortcut that puts user input directly into
  SQL.
tier-2-verbose: |
  Flipping the perf query parameter swaps the parameterized search
  for a raw concatenation of the search term into a LIKE clause.
  Standard string-quote-and-close payloads work. The endpoint is
  admin-only, so you'll need either a forged token or a chained
  bypass to reach it.
