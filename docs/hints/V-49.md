category: Infra / Supply chain
tier-1-basic: |
  A private-scope dependency is referenced without telling the
  package manager where to find it. The public registry is the
  fallback.
tier-2-verbose: |
  The web app declares an optional dependency under a private scope.
  No registry-scope pin exists. An attacker who registers a package
  with the same name on the public registry can ship code that the
  install path would pull in. The scope is the secret you need to
  find in the manifest.
