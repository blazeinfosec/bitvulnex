category: Crypto / Business logic — zero-conf credit
tier-1-basic: |
  Top-tier deposits are credited at zero confirmations. If the
  transaction is later replaced and dropped, the credit is not reversed.
tier-2-verbose: |
  A premium tier maps to zero required confirmations, so the deposit
  worker credits balance the moment a transaction appears in the
  mempool. Replace-by-fee the transaction so the original drops; the
  worker marks the deposit dropped but never debits the balance it
  already credited — there is no reconciliation. Reach the tier
  (legitimately or via an admin path), self-send a deposit, drop it,
  repeat. Balance grows with no on-chain settlement.
