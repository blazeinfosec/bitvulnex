category: OWASP / XSS / Upload
tier-1-basic: |
  KYC document upload trusts the uploaded mime type when the client
  hides the real one. Same-origin rendering picks up the trusted
  mime.
tier-2-verbose: |
  When the client sends a generic application/octet-stream, the
  server infers the mime from the filename's extension. A polyglot
  file that begins with image bytes but whose name ends in .html is
  served back with the html mime, inside an iframe whose blob URL
  shares the same origin. The admin viewer is the sink.
