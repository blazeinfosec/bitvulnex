target: V-10
category: OWASP / Auth — predictable token
tier-1-basic: |
  A reset token is generated from inputs an outside observer can
  reasonably predict. Knowing the inputs is the same as knowing
  the token.
tier-2-verbose: |
  The reset-link token reduces to a short prefix of a hash over the
  user id and the current epoch milliseconds. Both are observable
  or guessable in a tight window. Brute the few seconds around the
  request to find a token that the reset endpoint accepts.
