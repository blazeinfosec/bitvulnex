target: V-50
category: Infra / HTTP request smuggling
tier-1-basic: |
  The edge and the app disagree on request framing. Both a length header
  and a chunked header get through, and the app is told to tolerate it.
tier-2-verbose: |
  Two halves make this work: the reverse proxy forwards both a
  content-length and a chunked transfer-encoding header to the upstream,
  and the app process runs with a lenient HTTP parser that accepts the
  ambiguity instead of rejecting it. Send one request carrying both
  headers; the upstream desyncs on the chunked terminator and reads
  trailing bytes as a second request on the connection. Smuggle a
  privileged self-update onto a legitimate user's session. Finding only
  the proxy directives leaves you stuck until you also spot the parser
  flag.
