target: V-23
category: WebSocket / CSWSH
tier-1-basic: |
  The WebSocket gateway does not validate where the upgrade request
  came from. Anything that can establish the connection can subscribe.
tier-2-verbose: |
  The upgrade handler reads the access token from the query string
  and never checks the Origin header. A cross-origin page can open
  the socket with the victim's cookie-resident token. Once connected
  there's also no allow-list on the channel name passed to the
  subscribe message.
