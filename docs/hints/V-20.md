---
target: V-20
category: Auth / JWT — kid path traversal
tier-1-basic: |
  A token header field names which key to verify with. That name is
  turned into a file lookup without restriction.
tier-2-verbose: |
  The legacy verifier treats the token's key-id header as a filesystem
  location and reads whatever it points at, using the bytes as the
  HMAC secret. A traversal sequence in the key-id reaches a
  process-readable file whose contents you can predict; sign your
  token with those bytes as the secret and the legacy verify path
  accepts it. Whitelisting the key-id would have stopped this.
